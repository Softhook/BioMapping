GPS Filtering

Automatic: Fix ≥ 2D → Stop averaging → Speed filter → Velocity smoother (ZUPT). Tuned for pedestrian GSR mapping.

Path Responsiveness 0.5

How quickly the path responds to GPS movement. 0.1–0.3 = heavy smoothing (straight, stable). 0.5 = balanced (default). 1.0–2.0 = responsive (follows every wiggle).

GPS Precision 10 m²

How much you trust each GPS reading (measurement noise R). 5 = survey-grade / open sky. 10 = consumer GPS (default). 25–40 = urban canyon / poor signal.

Max HDOP ≤ 3.0

Rejects GPS fixes with poor satellite geometry. 2.0 = urban canyons, 3.0 = default, 5.0 = open sky (matches firmware pre-filter).

Max Speed 3.0 m/s

Rejects GPS jumps that imply impossible speeds. 3 = walking, 5 = running, 10 = cycling. Computes step-to-step speed to reject transient positioning leaps.

Display
RDP Simplification off

Path simplification (metres). 2–5 m preserves walking-path shape. 0 = off.

Downsample Path off

Downsample to 1 Hz for performance on large tracks. 0 = off, 1 = on.
