Noise Filtering
Artifact Median Filter 1.0 s

Removes sudden spikes/motion artifacts. Recommended: 0.3–1.0 s. Set to 0 = off.

Smoothing Low-Pass 0.8 s

Filters high-frequency electrical fuzz. Recommended: 0.3–1.0 s. Set to 0 = off.

Tonic/Phasic Split
Baseline Method
Tonic Baseline Window 15 s

Wider windows isolate baseline from peaks. Recommended: 10–30 s.

DWT Decomposition Level 6

Higher level = slower tonic (purer SCL) but more signal goes into phasic. Level 5–7 all work. Recommended: Level 6 (0–0.08 Hz).

GPS Filtering

Outlier Rejection
Min. Satellites 0

Hide points with fewer satellites. Recommended: 4–8. Set to 0 = off.

Max Speed Filter 5 m/s

Rejects GPS jump outliers by speed. Walking ≈ 1.4 m/s. Recommended: 3–7 m/s. Set to 0 = off.

Hampel Window 3 s

Spike removal via local median. Recommended: 2–5 s. May conflict with Kalman — use one or the other. Set to 0 = off.

Hampel Sigma 3.0

Outlier strictness. Recommended: 2.5–4.0 (3.0 = standard).

Smoothing & Clustering
DBSCAN Stop Radius 10 m

Groups stationary GPS wander. Recommended: 3–10 m. Kalman may partially undo centroiding. Set to 0 = off.

DBSCAN Min Duration 4 s

Min duration for a stationary stop. Recommended: 3–8 s.

Kalman Smoother R 0 m²

Measurement noise (m²). Recommended: 5–15 m² (consumer GPS). Set to 0 = off.

Kalman Smoother Q 0 m²

Process noise (m²). Recommended: 1–3 m² (walking ~1.4 m/s). Set to 0 = off.

RDP Simplification 5 m

Path simplification tolerance. Recommended: 2–5 m (preserves walking path shape). Set to 0 = off.

Downsample Path 1 Hz

Downsample path to 1 Hz to prevent browser lag (0 = off, 1 = 1 Hz). Not needed if RDP is active.

Map Display

Track Width 5 px

Thickness of the drawn GPS path on the map.

Peak Latency Compensation 0.0 s

Compensates for physiological SCR delay on map. Recommended: 1–3 s. Set to 0 = off.
